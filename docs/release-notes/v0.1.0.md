# Noosphere 3D v0.1.0

First public build of Noosphere 3D, a keyboard-first desktop app for free-form 3D mind maps. This is a **pre-release**. The installers are unsigned, and the Windows and macOS builds have not had a hands-on check on real hardware.

## What's in this MVP

- Keyboard-first 3D mind maps
- Maps stored as `.mindmap3d` files
- Autosave and crash recovery
- Tabs
- Command palette
- An accessibility tree for the selection

## Opening an unsigned build

macOS builds ship unsigned and not notarized. There is no Apple Developer account. Apple Silicon builds still carry an ad-hoc signature (`signingIdentity: "-"` in `src-tauri/tauri.conf.json`, which `.github/workflows/build.yml` leaves in place) so the system can open the file. Gatekeeper blocks the first launch. After that blocked launch, open the app from **System Settings → Privacy & Security → Open Anyway**. Right-clicking the app and choosing **Open** only works on older macOS versions.

On Windows, SmartScreen may say that it protected the PC. Choose **More info → Run anyway**.

## Known limitations

- macOS builds are unsigned and not notarized. Apple Silicon builds are ad-hoc signed only. Windows builds are unsigned.
- Screen-reader checks are still pending: Orca on Linux, NVDA on Windows, and VoiceOver on macOS.
- GPU frame-rate and label checks are still pending.
- OS shortcut checks on real Windows and macOS machines are still pending.
